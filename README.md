## 📌 About

Haryana Supplements is a modern full-stack e-commerce website developed for selling authentic gym supplements with a premium user experience.

The website includes product browsing, shopping cart, secure checkout, order management, admin dashboard, customer reviews, and responsive mobile-first design.

### Clone Repository

bash
git clone (https://github.com/vishal-jindal2006/Haryana-Supplements)

Go to project

bash
cd Haryana-Supplements

Install Backend Dependencies

bash
cd backend
npm install

Run Backend

bash
npm start
